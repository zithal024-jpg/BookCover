# BookCover 1.0.0

First public release.

- Offline reader for DRM-free EPUB and PDF books, with a private library, collections,
  search and Continue reading.
- Outside-cover display on supported foldables (tested on Samsung Galaxy Z Fold), with
  automatic or manual start, a 30/60-minute or manual timer and live appearance previews.
- Reading comfort settings, Paper / Sepia / Night pages, optional paper page turn, edge
  taps and volume-key turns.
- Contents, bookmarks, in-book search, chapter progress and time-left estimates.
- PDF original-page view, plus a Text view on Android 15+ for PDFs with selectable text.
- Reading streak, three relic sets (Moonlit Archive, Atlas, Hearthkeeper) and cover edges.
- Backup and restore of positions, bookmarks, collections, reading history and relics.
- No internet permission; nothing leaves your phone.

Install or update: see the [instructions](https://github.com/zithal024-jpg/BookCover-Releases#install). Check the download against the
`.sha256` file attached to this release.
